# Xtract — X動画セーバー

iPhone / Safari に合わせて設計した、公開Xポストの動画保存 PWA。

## 使い方
Xで公開ポストのURLをコピー → Xtractで貼付 → 動画を解析 → 動画・画質を選択 → ダウンロード。iPhoneでは共有シートから「ビデオを保存」を選択してください。Safariの「ホーム画面に追加」でPWAとして利用できます。

## 実装
- Vite (静的フロントエンド)、Vercel Node Functions (`/api/analyze`, `/api/media`)
- FxEmbed の公開 API v2 を優先して解析し、失敗した場合には X の公開埋め込み用 JSON を試行
- 動画の配信先は許可リストの HTTPS MP4 のみ。外部の不明な CORS プロキシは使用しない
- 動画ダウンロードは直接通信優先、CORSの制約があるときだけバックエンドのストリーミング転送
- ffmpeg.wasm による端末内の任意圧縮。35 MB以上はiPhoneのメモリ保護のため圧縮をスキップ
- 元データの動画は当サービスには保存しない。動画本体の転送は 120MB で制限
- PWAとしてのオフライン起動 (解析・保存には通信が必要)

## ローカル開発
`npm install`, `npm run dev`。画面とPWAは確認できますが `/api/` は Vercel の開発サーバーで実行してください (`vercel dev`)。
`npm test` でURL正規化・メディア抽出のユニットテストを実行します。

## 注意事項
公開動画であっても、著作権やXの利用規約に留意してください。非公開・削除済み・DRM保護された動画には対応しません。外部のFxEmbed APIやXの仕様変更によって解析できなくなる場合があります。iOS Safariでは大容量動画やメモリ制約により圧縮できない場合があります。端末内での変換は画質・容量が一定に保たれることを保証しません。
