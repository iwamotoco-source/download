# Download Tools — Xtract / Shrink

iPhone/Safari 対応の動画ツール2本を1リポジトリで運用するPWAサイト。

## URL
- `/` — ツール選択トップ
- `/x.html` — **Xtract**: 公開Xポストの動画を画質選択して保存
- `/shrink.html` — **Shrink**: 端末内でローカル動画をまとめて再エンコード

## Shrink の使い方
1. 「ファイルを選ぶ」で複数選択（フォルダ選択は対応ブラウザのみ）。
2. 画質 CRF 20/23/26/30、最大解像度 元/1080p/720p、音声 AAC 192/128/64 kbps を設定。
3. 「圧縮を開始」。1本ずつ処理し、失敗したファイルはキューに残して他のファイルに進む。
4. 完了ファイルは個別に「保存」、複数なら「すべて保存（ZIP）」→ ZIP完成後「ZIPを保存」をもう一度タップ。iPhoneでは共有シートから「ファイルに保存」。

**入力ファイルはブラウザで処理し、サーバーや第三者サービスにはアップロードされません。** 初回だけ ffmpeg.wasm の実行ファイルを CDN からダウンロードします。ZIP生成も端末内のみ。

- 出力動画は H.264/AAC の MP4。圧縮後の容量が増加した場合は元のファイルを採用し、元のファイル拡張子を維持します。
- ZIPは無圧縮 (動画はすでに圧縮済み)。重複ファイル名は ` (2)` のように自動区別。
- iPhoneではメモリ負荷のため1ファイル60MB超は圧縮せず保持。デスクトップは150MB超。ZIPの上限は iPhone 190MB / デスクトップ 600MB。超過時は個別保存可能。
- 外部CDNが利用できない場合、HEVC等の非対応コーデック、メモリ不足、低性能端末、iOSのバックグラウンド処理制限では圧縮できない場合があります。CRFが小さくても元画質と完全同一にはなりません。
- フォルダ選択や複数ファイル共有、ネイティブ保存はブラウザの対応状況に依存します。iPhoneでは Safari で開いてください。

## Xtract
Xの公開ポストURLを貼り付け→解析→動画と画質を選択→取得→「保存する」をタップして共有。解析は Vercel Functions (FxEmbed / X公開埋め込み) を利用。非公開ポストやDRMは対象外。SNSの規約と権利者の許諾を守ってください。

## 開発
```sh
npm install
npm test
npm run build
npm run dev
```
Vercelの `download` プロジェクトへ `main` から自動デプロイ。
Vite マルチページビルドとVercel Functionsを使用。Xtract の /api は Vercel環境で動きます。

## PWA
XtractとShrinkは別の `id` / `start_url` とアイコンを持ち、ルート配下の単一サービスワーカーを共有。ビルド済みJSやシェルはネットワーク優先でキャッシュし、次回オフライン時に静的UIへフォールバックできます。ただし初回エンコーダの取得には通信が必要です。

## アイコン
Xtractは提供画像のアイコン、Shrinkは同じ配色に合わせた独立アイコンを採用。


### Xtractの大容量動画対応
- 旧バージョンの120MB上限は撤廃。選んだ動画のサイズを軽量プローブで確認し、約70MBを超える場合は自動で「大容量モードで保存」を選択します。
- 大容量モードはブラウザの通常のダウンロード機能を使用し、動画全体を JavaScript の Blob に集めません。Vercelの Functions は許可済みのMP4配信元からデータを逐次中継し、転送経路に1GBの保護上限を設けます。
- ファイルはまずSafariのダウンロード先（「ファイル」アプリ）に入ります。写真アプリへ保存したい場合はファイルから共有→ビデオを保存。
- 少量ファイルは従来の共有シート保存も利用できます。軽量化処理は35MB以下のみ推奨（大きい動画は圧縮せず元を直接保存）。
- サーバー中継は通信環境やVercelの実行時間・転送制限に影響されるため、あらゆるサイズの成功は保証しません。
